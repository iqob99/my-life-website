我的第一个网页是怎样做出来的

我的第一个网页并不是一开始就很复杂。最初，我只创建了一个 HTML 文件，让一句文字出现在浏览器里。

先让页面出现

HTML 负责网页的结构。标题使用 h1，普通文字使用 p，链接使用 a。理解这些基本标签后，我开始把个人介绍放进页面。

再用 CSS 美化

CSS 负责颜色、间距、字体和布局。每次修改后刷新浏览器，我都能立刻看到变化，这让学习变得很有成就感。

后来，我又加入了图片、深色模式、留言表单和学习时间线。一个小页面就这样慢慢成长起来了。
